# AI 上下文使用说明

最后更新：2026-11-21。

## 阅读顺序

1. [档案首页](../README.md)：掌握整体定位。
2. [当前状态](../profile/now.md)：了解当前阶段。
3. [个人介绍](../profile/about.md) 与 [职业经历](../profile/experience.md)：补齐背景。
4. 按任务阅读业务、作品与内容文档。
5. [事实与表达边界](facts-and-boundaries.md)：遵守事实状态与表述要求。

## 事实优先级

Rycan 最新明确确认的信息优先于旧记录。当前职业与创业状态以 `profile/now.md` 为准。出现冲突时保留已确认的新信息，记录需要修正的旧条目。

文档中的验证问题、模板与待补充项属于工作框架，不代表已有事实或经营成果。
