# Rycan 个人档案

> 以技术、产品与商业的复合视角，推动 AI 解决真实业务问题。

我是 Rycan，一名拥有软件研发、产品管理、售前与云解决方案架构经验的创业者。曾在国内头部云厂商从事解决方案架构工作，目前已离职，全职投入 AI 领域创业。
